# Release notes
Each release needs a section whose title matches the version in package.json.
Add a line "requires: 2.1.0" inside a section to make that update mandatory for older installs.

## 2.2.0
- New Auto transaction detection: paste a bank or wallet message and Khata drafts the entry for your review
- Android APK can read money notifications after you allow notification access (off until you enable it)
- Duplicate protection, review list, imported history, and a delete-history button

## 2.1.0
- New update screen with release notes and a Later button
- Updates download safely in the background; your records are never touched
- Clear error messages and Retry if you are offline or the download fails

## 2.0.0
- Zero-start balances, savings goals, validated backups and restore
